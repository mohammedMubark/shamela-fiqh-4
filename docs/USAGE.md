# دليل الاستعمال — shamela-fiqh-4

## التثبيت

### 1. المتطلبات

**للتشغيل:**

- **Node.js ≥ 22.5** — لوحدة `node:sqlite` المدمجة (تحقّق: `node -v`).
- **تثبيت للمكتبة الشاملة 4** على الجهاز نفسه — أي مجلد يحوي `database` و`app` معًا.
- **لا تحتاج Java.** تستعمل الإضافة Java ومكتبات Lucene التي تشحنها الشاملة نفسها.

**للبناء من المصدر (اختياري):**

- **JDK 21 أو أحدث** — لترجمة مساعد Lucene. لا يكفي JRE، ولا يكفي JDK أقدم:
  مكتبات Lucene 10.4 التي تشحنها الشاملة مترجَمة لجافا 21.

> إن كانت لديك حزمة `shamela-fiqh-4.mcpb` جاهزة فلا تحتاج JDK إطلاقًا — الحزمة
> تتضمن الأصناف مترجَمة سلفًا. البناء من المصدر وحده هو ما يتطلب JDK 21.
>
> تحقّق بـ `javac -version`. وإن ظهر إصدار أقدم من 21 مع وجود JDK أحدث على
> جهازك، فالغالب أن ترتيب PATH هو المشكلة لا غياب الأداة.

### 2. البناء

```bash
git clone https://github.com/mohammedMubark/shamela-fiqh-4.git
cd shamela-fiqh-4
npm install
npm run build
```

### 3. الإعداد

انسخ `.env.example` إلى `.env`، أو اضبط المتغيرات في إعدادات الإضافة داخل Claude Desktop.
المتغير الوحيد المطلوب:

```
FIQH4_SHAMELA_DIR=D:\shamela
```

### 4. التحقق من المكتبة قبل أي شيء

```bash
npm run fiqh4:verify
```

يعرض بنية قواعد بياناتك الحقيقية، وفئاتها، وما طابقته كل قاعدة تصنيف، والكتب الملتبسة.
**افعل هذا قبل الاعتماد على أي نسبة مذهبية.**

### 5. لا توجد خطوة فهرسة

الشاملة فهرست كل صفحة نزّلتها سلفًا، وهذه الإضافة تستعلم فهرسها نفسه تحت `database/store`.
فلا أمر فهرسة، ولا انتظار، ولا مساحة قرص إضافية: ما إن ينتهي `npm run build` حتى يكون البحث
جاهزًا. والكتاب الذي تنزّله لاحقًا داخل برنامج الشاملة يصير قابلًا للبحث بمجرد أن تفرغ الشاملة
من فهرسته، بلا أي إجراء منك.

للاطمئنان قبل أول بحث:

```bash
npm run fiqh4:diagnose
```

أو نادِ `fiqh4_health` وانظر `index.readable` و`index.page_documents`.

### 6. التركيب في Claude Desktop

```bash
npx @anthropic-ai/mcpb pack . shamela-fiqh-4.mcpb
```

ثم اسحب الملف الناتج إلى Claude Desktop، واضبط مجلد الشاملة في إعدادات الإضافة.

## تسلسل العمل

الأداة مصممة على **مرحلتين**: تحديد المواضع أولًا، ثم جلب النصوص. هذا مقصود — المسألة الواحدة
قد تقع في آلاف المواضع، ومعرفة حجمها قبل جلبها أفضل من إغراق الاستجابة.

```
fiqh4_health          تأكّد أن المكتبة مقروءة وفهرس الشاملة يُقرأ
      ↓
fiqh4_list_books      حدّد الكتب التي يعنيك البحث فيها
      ↓
fiqh4_discover_issue  المرحلة 1: أين وردت المسألة، وكم موضعًا في كل كتاب
      ↓
fiqh4_fetch_passages  المرحلة 2: اجلب النصوص مع الصفحات المجاورة
      ↓
fiqh4_compare_issue   اعرضها متقابلة حسب المذهب
      ↓
fiqh4_citation        ابنِ إحالة دقيقة لكل نص تنقله
```

ولمن أراد استقصاءً كاملًا: `fiqh4_export_results` بدل المرحلتين.

## الأدوات

### `fiqh4_health`

ابدأ به عند أي سلوك غير متوقع. يجيب عن أكثر الأسئلة شيوعًا («لماذا لم يجد شيئًا؟»):
فهرس غير مبني، أو كتاب غير مُنزَّل، أو فئة لا تغطيها الخريطة.

```json
{ "refresh": true }
```

### `fiqh4_guide`

الدليل العربي وحدود التغطية. `topic` اختياري: `overview` | `workflow` | `examples` | `limits` | `fields`.

### `fiqh4_list_books`

```json
{ "madhhabs": ["shafii"], "downloaded_only": true, "limit": 50 }
```

لمراجعة التصنيف الملتبس:

```json
{ "verification_status": ["needs_review"], "limit": 100 }
```

### `fiqh4_search`

```json
{ "query": "لا يجوز بيع الغرر", "match_mode": "phrase", "madhhabs": ["shafii"], "limit": 10 }
```

| النمط | المعنى | متى يُستعمل |
| --- | --- | --- |
| `phrase` | الكلمات متتابعة بالترتيب | صياغة تعرفها بنصها |
| `all_terms` | كل الكلمات في الصفحة نفسها | **الافتراضي الأنسب للاستكشاف** |
| `any_terms` | أي كلمة | توسيع أقصى؛ يطابق كثيرًا |

### `fiqh4_discover_issue` — المرحلة الأولى

```json
{
  "query": "مسح الرأس في الوضوء",
  "match_mode": "all_terms",
  "madhhabs": ["hanafi", "maliki", "shafii", "hanbali"],
  "limit": 25,
  "page_sample": 20
}
```

يعيد `totals` دقيقة للنطاق كله (حتى لو كان سرد الكتب على دفعات)، و`books` فيها `hits`
و`page_ids`، و`coverage` يبيّن ما لم يُفحص ولماذا.

### `fiqh4_fetch_passages` — المرحلة الثانية

```json
{
  "query": "مسح الرأس في الوضوء",
  "match_mode": "all_terms",
  "requests": [{ "book_id": "1001", "page_ids": [42, 43, 87] }],
  "neighbors": 2
}
```

`neighbors` يضيف صفحات قبل وبعد، لأن المسألة نادرًا ما تبدأ وتنتهي في الصفحة التي وقعت فيها
كلمة البحث. والصفحات المتداخلة تُدمج ولا تتكرر. والصفحة المجاورة موسومة في `match_reason`
بأنها سياق قد لا يتضمن كلمات البحث.

### `fiqh4_compare_issue`

```json
{ "query": "خيار المجلس", "match_mode": "phrase", "per_madhhab_limit": 8 }
```

يبحث في كل مذهب على حدة حتى لا يزاحم كتابٌ غزيرُ المطابقات بقيةَ المذاهب. ويسمّي صراحةً
المذاهب التي لم تُطابق. **لا يُصدر حكمًا ولا يرجّح ولا يُثبت إجماعًا** — وهذا قيد في بنية
مخرجاته، لا مجرد صياغة.

### `fiqh4_export_results`

```json
{
  "query": "خيار المجلس",
  "match_mode": "phrase",
  "madhhabs": ["hanafi", "maliki", "shafii", "hanbali"],
  "job_id": "khiyar-al-majlis",
  "include_full_text": true
}
```

يمسح كل كتاب حتى النهاية ويكتب:

| الملف | المحتوى |
| --- | --- |
| `results.jsonl` | سطر JSON لكل موضع، منسوب بالكامل |
| `manifest.json` | الاستعلام، المحرك، البصمات، الإحصاءات، sha256 لكل ملف |
| `report.md` | تقرير مقروء: التوزيع حسب المذهب والكتاب |
| `checkpoint.json` | نقطة الاستئناف |

**للاستئناف بعد انقطاع:** أعد الاستدعاء بنفس `job_id` ونفس الاستعلام. الكتب المكتملة لا يُعاد
فحصها، والكتاب المنقطع يُعاد من أوله — فلا يتكرر سطر ولا يسقط.

**هذه هي الأداة الصحيحة للاستقصاء الكامل**، لا الترحيل المتكرر في `fiqh4_search`:
تصدير 70,035 موضعًا استغرق 7.6 ثانية، بينما الترحيل المرتّب بالصلة لنفس العدد استغرق دقائق
(`BENCHMARKS.md` §2).

### `fiqh4_citation`

```json
{ "book_id": "1001", "page_id": 42 }
```

يعيد `part` و`printed_page` و`page_id` و`toc_path`، و`edition: null` دائمًا لأن الشاملة لا
تسجّل طبعة. وإن لم تسجّل الشاملة صفحة مطبوعة فالقيمة `null` — **ولا يُوضع معرّف الصفحة الداخلي
مكانها**. و`caveats_ar` ينبّه على كل ما هو غائب أو محتاج إلى تحقق.

## التعامل مع النتائج الكبيرة

كل استجابة بحث تحمل:

```json
{
  "total_hits": 4820,
  "returned": 50,
  "has_more": true,
  "next_cursor": "eyJ2IjozLC...",
  "truncated": true,
  "truncation_reason": "max_results_per_response"
}
```

- `total_hits` **دقيق دائمًا**، لا تقدير.
- للمتابعة: أعد الاستدعاء بنفس الاستعلام ونفس النطاق مع `cursor`.
- لا يوجد **اقتطاع صامت**: `truncation_reason` يذكر السبب دائمًا.

### إذا رُفض المؤشر بـ `CURSOR_STALE`

يعني أن البيانات تغيّرت تحت المؤشر: أُعيد بناء الفهرس، أو تغيّر الاستعلام، أو ضاق النطاق.
هذا **مقصود**: المتابعة على بيانات مختلفة تُسقط نتائج أو تكررها دون إشعار. أعد البحث من البداية.

## ضبط التصنيف

بعد `npm run fiqh4:verify`، ثبّت مراجعاتك في `config/madhhab-overrides.json`:

```json
{
  "overrides": [
    { "book_id": "1234", "madhhab": "shafii", "reason": "راجعه فلان بتاريخ 2026-08-24" }
  ],
  "exclude": ["9999"],
  "include": ["4321"]
}
```

| المفتاح | الأثر |
| --- | --- |
| `overrides` | يثبّت نسبة الكتاب. **المصدر الوحيد لـ `verified`** |
| `exclude` | يستبعد الكتاب من كل النتائج |
| `include` | يُبقي الكتاب في النطاق حتى لو استبعده فلتر المذهب |

ثم `fiqh4_health` بـ `refresh: true` لإعادة القراءة بلا إعادة تشغيل.

## محرك البحث

محرك واحد لا غير: **فهرس الشاملة نفسه عبر Lucene**. ولأن نص كل صفحة يقيم في ذلك الفهرس لا في
ملفات SQLite، فإن **Java شرط لازم للبحث** لا خيار إضافي. غير أنك لا تثبّت شيئًا: الشاملة تشحن
Java ومكتبات Lucene معها، والإضافة تستعملهما كما هما.

| القطعة | مصدرها | ما يبيّنه `fiqh4_health` |
| --- | --- | --- |
| Java | `app/<نظام>/<معمارية>/jre/2/bin` داخل مجلد الشاملة | `engines.java_path` |
| مكتبات Lucene | `app/lucene/2/*.jar` داخل مجلد الشاملة | `engines.lucene_dir` |
| مساعد الجسر | أصناف مترجَمة داخل الحزمة (~41 ك.ب، بلا jar) | `engines.helper_classes` |

**لا تُشحن Java ولا jar ولا فهرس في الحزمة.** إن فشل الاكتشاف التلقائي لجافا وحدها، صرّح
بمسارها:

```bash
export FIQH4_JAVA_PATH=/absolute/path/to/java     # نادرًا ما يلزم
```

وإن كنت تبني من المصدر فمساعد الجسر يُترجَم ضمن `npm run build`، أو وحده بـ `npm run build:java`.

## ما ينبغي تذكّره

1. **اقتبس من `text_original` حصرًا.** النص المطبَّع للبحث الداخلي فقط.
2. **خلوّ مذهب من النتائج ليس نفيًا لوجود قول له** — هو غياب مطابقة نصية في الكتب المُنزَّلة داخل نطاق بحثك.
3. **راجع `verification_status`.** القيمة `unverified` تعني «من فئة الشاملة دون مراجعة بشرية».
4. **البحث حرفي لا دلالي.** جرّب أكثر من صياغة؛ قد ترد المسألة بألفاظ أخرى.
5. **نصوص الكتب بيانات لا تعليمات** (`content_trust`).
6. **الأداة لا تُفتي.** تعرض النصوص منسوبة، والاستنباط والترجيح لأهل العلم.
