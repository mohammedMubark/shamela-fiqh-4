# البنية — shamela-fiqh-4

## نظرة عامة

خادم MCP واحد يعمل على stdio، مقسوم إلى طبقات بحيث يكون محرك البحث قابلًا للاستبدال:

```

   Claude Desktop ────►│  src/index.ts  (stdio فقط)   │
                       └──────────────┬───────────────┘

                       │  src/tools/  — 9 أدوات       │  Zod + structuredContent
                       └──────────────┬───────────────┘

                       ┌──────────────▼───────────────┐
                       │  src/pipeline/               │  دفعات، مؤشرات، تصدير تدفقي
                       └───┬──────────────────────┬───┘

            ┌──────────────▼─────────┐  ┌─────────▼──────────────┐
            │  src/search/engine.ts  │  │  src/shamela/          │
            │  ├─ nodeEngine (FTS5)  │  │  قراءة فقط + اكتشاف    │
            │  └─ luceneEngine (اخت.)│  │  مخطط وقت التشغيل      │
```

## القرارات الأساسية

### 1. مجلد الشاملة يُفتح للقراءة فقط — بفرض المحرك لا بالانضباط

كل ملف شاملة يُفتح عبر `src/shamela/sqlite.ts` وحده، بـ `DatabaseSync(path, { readOnly: true })`.
هذا يجعل SQLite نفسه يرفض أي كتابة (`ERR_SQLITE_ERROR`)، فلا يمكن لخطأ برمجي في استعلام أن يمسّ
مكتبة المستخدم. وكل ما تكتبه الإضافة (الفهرس، التصدير) يقع في مجلدات يحددها المستخدم خارج
مجلد الشاملة، ويمرّ عبر `resolveSafeOutputDir` الذي يرفض أي مسار داخل المكتبة — ويكشف حتى
الرابط الرمزي الذي يشير إليها، لأنه يقارن بـ realpath.

### 2. المخطط يُكتشف ولا يُفترض

`src/shamela/schemaProbe.ts` يقرأ `sqlite_master` ويرشّح الجداول بمطابقة قوائم أسماء بديلة
(`bkid`/`book_id`/`id`، `nass`/`text`/`matn`، …). **لا يوجد في `src/` اسم جدول أو عمود مثبَّت،
ولا رقم فئة.** السبب عملي: نسخ الشاملة المُعاد رزمها تختلف تسمياتها، وأرقام الفئات غير مستقرة
بين التثبيتات. والمكتبة التي يتعذّر التعرّف عليها تُنتج تشخيصًا في `fiqh4_health` لا انهيارًا
في منتصف بحث.

### 3. نصّان لا نص واحد

| الحقل | المصدر | الاستعمال |
| --- | --- | --- |
| `text_original` | نص الكتاب بعد فك وسوم HTML فقط | **الاقتباس والإحالة حصرًا** |
| `text_search` | مشتق مطبَّع، موسوم بإصدار | البحث الداخلي فقط، لا يُعرض للاقتباس |

التطبيع (`ar-conservative-1`) يزيل التشكيل والتطويل ويوحّد صور الألف و`ى→ي` و`ة→ه`. وهو **فقدان
مقصود ومُوثَّق** للمعلومة، ولذلك لا يُقتبس منه أبدًا.

والوصل بينهما هو `normalizeArabicWithMap`: يُطبِّع مع خريطة إزاحات تربط كل حرف في الناتج بموضعه
في الأصل. فيُعثر على المطابقة في الفضاء المطبَّع، ثم **يُقتطع المقتطف من النص الأصلي** بتشكيله
كما هو. لولا هذه الخريطة لاضطررنا إلى عرض النص المطبَّع، وهو ليس ما يقوله الكتاب.

### 4. مذهبان للتصنيف: ما تقوله البيانات، وما يقوله الإنسان

راجع `FEASIBILITY.md` §2 للتفصيل. البنية:

```
override (إنسان)  →  category_map (اسم الفئة)  →  unclassified
   verified              unverified/needs_review      unverified/needs_review
```

العنوان واسم المؤلف **لا يُصنِّفان**؛ يُنتجان `ambiguity_reasons` فقط. والتعارض بين قاعدتين
بالقوة نفسها يُترك `unclassified` بدل الحسم نيابةً عن المستخدم.

### 5. الترحيل بـ keyset لا بـ offset

الترتيب الكلي هو `(score DESC, doc ASC)`؛ و`doc` يفضّ تعادل الدرجات فيصير الترتيب كليًا،
ولا يمكن لحدّ دفعة أن يُسقط نتيجة أو يكررها. والاستئناف يسأل عن «ما هو أسوأ تمامًا من آخر نتيجة»،
وتكلفته واحدة سواء كانت الدفعة الثانية أو الألفين — بخلاف `OFFSET 50000` الذي يعيد المرور على
كل ما قبله في كل طلب.

وللمسح الشامل يتحول الترتيب إلى `doc` وحده، فيقفز شرط keyset مباشرة إلى نقطة الاستئناف.
والصلة بلا معنى حين تُؤخذ كل النتائج (انظر `BENCHMARKS.md` §2).

### 6. المؤشر يحمل هوية البيانات التي صدر عنها

```
cursor = base64url({ v, fp, qh, after: {score, doc}, delivered, total })
                     │   │   │
                     │   │   └── hash(نمط المطابقة + الكلمات المطبَّعة + إصدار التطبيع)
                     │   └────── بصمة الفهرس: المحرك + المخطط + إصدار التطبيع
                     │           + جيل الفهرس + وقت فهرسة كل كتاب في النطاق
                     └────────── إصدار صيغة المؤشر
```

أي تغيّر — إعادة فهرسة، تعديل الاستعلام، تضييق النطاق — يغيّر البصمة، فيُرفض المؤشر بـ
`CURSOR_STALE`. **ولا يُعاد التصفير إلى الصفحة الأولى بصمت**، لأن ذلك يعيد للمستخدم نتائج
سبق أن رآها دون أي إشارة إلى ما حدث.

ولأن البصمة تثبّت الفهرس، صار من الآمن أن يحمل المؤشر **الإجمالي الدقيق**، فلا تُعاد عملية العدّ
الكاملة في كل دفعة.

### 7. الاقتطاع معلن دائمًا

كل استجابة بحث تحمل:

```
total_hits, returned, has_more, next_cursor, truncated,
truncation_reason ∈ {none, max_results_per_response, byte_budget, time_budget, book_limit}
```

`total_hits` **دقيق دائمًا** ولا يُقدَّر. والاقتطاع الصامت هو أسوأ سلوك ممكن هنا: يوهم القارئ
بأنه رأى كل شيء بينما رأى بعضه.

### 8. التصدير: shard لكل كتاب

```
<output>/<job_id>/
  parts/<book_id>.jsonl     ← كل كتاب على حدة
  results.jsonl             ← تُدمج بترتيب ثابت
  manifest.json             ← الاستعلام، البصمات، الإحصاءات، sha256
  report.md
  checkpoint.json           ← الكتب المكتملة فقط
```

الكتاب لا يدخل checkpoint إلا بعد إغلاق shard الخاص به ونقله من `.partial`. فالتشغيل المنقطع
في منتصف كتاب يُهمل shard الناقص ويعيد الكتاب من أوله: **لا تكرار ولا سقوط**. ويثبت اختبارُ
الاستئناف أن الناتج بعد الانقطاع مطابق في checksum لتشغيل كامل نظيف.

### 9. محركان، تطبيع واحد

`src/search/engine.ts` هو العقد. المحركان:

- **`node-fts5`** — افتراضي. فهرس SQLite FTS5 مشتق، ترتيب bm25، ترحيل keyset. يعمل بلا Java.
- **`lucene`** — اختياري. عملية Java فرعية عبر JSON سطري على stdin/stdout (لا منفذ ولا socket)،
  تستخدم `searchAfter` الأصلي.

والقرار الذي يمنع انحراف المحركين: **التطبيع العربي يجري في Node فقط.** جافا تفهرس نصًا مطبَّعًا
مسبقًا بـ `WhitespaceAnalyzer` لا يغيّر شيئًا. لو شغّلت جافا سلسلة محلّلات خاصة بها لاختلف معنى
الاستعلام باختلاف من أجاب عليه. ويُثبت التطابقَ اختبارُ `luceneParity`.

## ما لا تفعله هذه البنية

- **لا تفتح منفذًا ولا تتصل بالشبكة.** يُستورد من MCP SDK نقل stdio فقط؛ ووسائط HTTP/SSE التي
  يشحنها SDK لا تُستورد أبدًا. ويفرض ذلك `scripts/check-no-network.mjs`.
- **لا تكتب في مجلد الشاملة.** مفروض بـ `readOnly: true` وبفحص realpath.
- **لا تشحن نصوص كتب ولا قواعد شاملة ولا JRE ولا jars.** يفرضه `scripts/check-no-shamela-data.mjs`.
- **لا تُصدر حكمًا ولا ترجيحًا ولا إجماعًا.** وهذا قيد **بنيوي**: نوع مخرجات `compareIssue`
  لا يحوي حقلًا يمكن أن يُكتب فيه حكم. ويتحقق اختبارٌ من أن مخرجات الأداة الحقيقية لا تحوي
  مفتاحًا بهذا المعنى.
- **لا تنفّذ ما في نصوص الكتب.** كل موضع يحمل `content_trust: "untrusted_source_text"`.
