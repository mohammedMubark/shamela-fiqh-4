# سياسة المصادر والنصوص — shamela-fiqh-4

هذه الوثيقة تحدد ما تفعله الأداة بالنصوص، وما لا تفعله، ولماذا. وهي المرجع عند أي شك في
مصداقية نتيجة.

## 1. النص الأصلي هو المرجع الوحيد للاقتباس

| الحقل | ما هو | يُقتبس منه؟ |
| --- | --- | --- |
| `text_original` | نص صفحة الكتاب بعد فكّ وسوم HTML فقط | ✅ **نعم، وهو وحده** |
| `excerpt` | مقتطف مقطوع من `text_original` على حدود الكلمات | ✅ نعم |
| `text_search` | صورة مطبَّعة مشتقة، مخزَّنة في الفهرس | ❌ **لا، أبدًا** |

`text_search` **لا يُعاد في أي استجابة أداة**. يوجد داخل الفهرس فقط، ولا يُستعمل إلا في المطابقة
وفي صياغة `match_reason`.

### كيف يبقى الاقتباس أمينًا

المطابقة تقع في الفضاء المطبَّع، لكن المقتطف يُقتطع من الأصل. الوصل بينهما خريطة إزاحات
(`normalizeArabicWithMap`) تربط كل حرف في الناتج المطبَّع بموضعه في النص الأصلي. فحين يُطابق
البحثُ «الصلاه»، يُعاد للقارئ ما يقوله الكتاب فعلًا: «الصَّلَاة» بتشكيلها.

## 2. التطبيع العربي: `shamela-compat-1`

التطبيع **فقدان مقصود للمعلومة**، غرضه الوحيد أن يجد من يكتب بلا تشكيل ما هو مشكول في الكتاب.

والقواعد ليست اختيارًا أسلوبيًا: **الإضافة تستعلم فهرس الشاملة نفسه**، والمصطلحات فيه مطويّة
بقواعد محلّل الشاملة. فالكلمة المطويّة بقواعد أخرى لا تطابق ما خزّنته الشاملة. ولذلك تُطابق
القواعد أدناه قواعدَها حرفًا بحرف.

### ما يُزال

| | |
| --- | --- |
| التشكيل | U+064B–U+065F، والألف الخنجرية U+0670، وعلامات الضبط U+06D6–U+06ED |
| التطويل | U+0640 |
| المحارف الصفرية | U+200B–U+200F، U+202A–U+202E، U+2060–U+2064، U+FEFF |

### ما يُوحَّد

| من | إلى | |
| --- | --- | --- |
| `آ` `أ` `إ` `ٱ` | `ا` | صور الهمزة على الألف |
| `ى` `ی` | `ي` | الألف المقصورة والياء الفارسية |
| `ؤ` | `و` | الواو المهموزة — **تطويها الشاملة، فنطويها** |
| `ة` | `ه` | التاء المربوطة |
| `گ` `ک` | `ك` | الكاف الفارسية |
| `پ` → `ب`، `چ` → `ج` | | حروف فارسية |
| `٠`–`٩` `۰`–`۹` | `0`–`9` | الأرقام |
| الرمز `ابن` | `بن` | تخزّنه الشاملة هكذا، فالبحث عن كنية لا يجد شيئًا بدونه |

### ما **لا** يُوحَّد — وهذا مقصود

| | |
| --- | --- |
| `ئ` | لا تطويها الشاملة، فلا نطويها — «سائل» تبقى غير «سايل» |
| **لا تجذير إطلاقًا** | «كتب» تبقى غير «كتاب»، و«ضرب» غير «ضارب» — التجذير يدمّر دقة الإحالة |

### تصادمات مقبولة، مُعلنة

| | | |
| --- | --- | --- |
| `على` ≡ `علي` | حرف الجر يساوي العلم | أثر الألف المقصورة |
| `مؤمن` ≡ `مومن` | | الواو المهموزة — تفرضه الشاملة |
| `الصلاة` ≡ `الصلاه` | | التاء المربوطة |
| `إجماع` ≡ `اجماع` | | صور الألف |

هذه تصادمات حقيقية. وقد قُبلت لأن بديلها — ألا يجد من يكتب «الصلاه» شيئًا — أسوأ.
ويتحقق ملف `tests/unit/normalize.test.ts` من كلا الطرفين: أن الاندماجات المقصودة تقع،
وأن الكلمات المتمايزة **لا** تندمج.

### الإصدار

`NORMALIZER_VERSION = "ar-conservative-1"` مضمَّن في بصمة الفهرس. فتغيير القواعد يبطل كل مؤشر
سابق ويوجب إعادة بناء الفهرس، بدل خلط نتائج بُنيت بقواعد مختلفة.

## 3. كل موضع منسوب بالكامل

| الحقل | القيمة عند الغياب |
| --- | --- |
| `book_id` `title` `author` | — |
| `madhhab` + `classification_source` + `verification_status` | — |
| `page_id` | معرّف الصفحة في قاعدة الكتاب |
| `part` | **`null`** إن لم تسجّله الشاملة |
| `printed_page` | **`null`** إن لم تسجّله الشاملة |
| `toc_path` | **`[]`** إن لم يكن للكتاب فهرس |
| `query` + `match_mode` + `score` + `match_reason` | — |
| `numbering_note` | تصريح بأن الترقيم ترقيم الشاملة |
| `content_trust` | `"untrusted_source_text"` دائمًا |

## 4. ما لا يُخترع أبدًا

هذا القسم هو جوهر السياسة.

| | السلوك |
| --- | --- |
| **الطبعة** | `edition` **دائمًا `null`**. الشاملة لا تسجّل طبعة، وطبعة مختلَقة تبدو موثوقة أخطر من غيابها |
| **الصفحة المطبوعة** | `null` إن لم تُسجَّل. **ولا يوضع `page_id` مكانها** |
| **الجزء** | `null` إن لم يُسجَّل |
| **مسار العنوان** | `[]` إن لم يوجد فهرس. لا يُخترع اسم باب |
| **نسبة المذهب** | `unclassified` عند عدم الحسم، لا تخمين |
| **الإجماع** | لا يُستنتج ولا يُعلن **بأي حال** |
| **الترجيح** | لا يقع. عدد المواضع ليس دليل قوة |

`score` درجة ترتيب داخلية للمحرك، تصلح للمقارنة **داخل نتيجة واحدة فقط**. ليست حكمًا على أهمية
النص ولا على قوة القول، ولا تُقارن بين محرك وآخر.

## 5. نصوص الكتب محتوى غير موثوق

كل موضع يحمل `content_trust: "untrusted_source_text"`.

نص الكتاب **بيانات، لا تعليمات**. لو تضمّنت صفحة ما نصًّا يشبه أمرًا موجّهًا إلى نموذج لغوي،
فهو محتوى الصفحة لا طلبٌ يُنفَّذ. تعليمات الخادم وأوصاف الأدوات تنص على ذلك، وهو مذكور في
`fiqh4_guide`.

## 6. الأداة ليست جهة فتوى

`fiqh4_compare_issue` يجمع النصوص وينسبها إلى مصادرها. **ولا يُصدر حكمًا، ولا يرجّح، ولا يُثبت
إجماعًا.**

وهذا **قيد بنيوي لا صياغة لطيفة**: نوع المخرجات لا يحتوي حقلًا يمكن أن يُكتب فيه حكم، ويتحقق
اختبارٌ من أن مخرجات الأداة الحقيقية خالية من أي مفتاح بهذا المعنى.

### غياب المذهب من النتائج

عبارة تتكرر في مخرجات الأداة عمدًا:

> لم تُطابق أي صفحة في الكتب المفهرسة المنسوبة إلى \[المذهب]. هذا نتيجة بحث نصي، وليس نفيًا
> لوجود قول في المذهب.

الأسباب المحتملة: الكتاب غير مُنزَّل، أو غير مفهرس، أو مصنَّف تحت مذهب آخر، أو المسألة واردة
بألفاظ أخرى، أو الفئة غير مغطاة بالخريطة. **ولا يعني شيء من ذلك أن المذهب لا قول له.**

## 7. نسبة الكتب إلى المذاهب

راجع `FEASIBILITY.md` §2 للتفصيل. الملخّص:

| `classification_source` | `verification_status` | ما يعنيه |
| --- | --- | --- |
| `override` | `verified` | راجعه إنسان وكتبه في ملف التجاوزات |
| `category_map` | `unverified` | من فئة الشاملة، بلا مراجعة بشرية |
| `category_map` | `needs_review` | من الفئة، لكن ثمة إشارة متعارضة |
| `unclassified` | `needs_review` | إشارة في العنوان أو المؤلف، ولا فئة تحسم |
| `unclassified` | `unverified` | لا فئة ولا إشارة |

### النطاق: الأقسام الأربعة فقط

خريطة الفئات مضبوطة على أسماء أقسام الشاملة الأربعة **مطابقةً تامة**:
«الفقه الحنفي» و«الفقه المالكي» و«الفقه الشافعي» و«الفقه الحنبلي».

المطابقة تامة لا جزئية عمدًا: القسم الذي يحتوي اسم مذهب دون أن يكون فقهه — «أصول الفقه الحنبلي»
مثلًا — علمٌ آخر، ومطابقته الجزئية كانت ستوسّع المدوّنة بصمت. وكذلك «الفقه العام» و«علوم الفقه
والقواعد الفقهية»: خارج النطاق، وتبقى `unclassified`.

من أراد إدراج قسم آخر أدرجه صراحةً في `config/madhhab-overrides.json`، فيظهر بـ
`classification_source: "override"` ويُعرف أنه اختيار بشري لا استنتاج آلي.

**العنوان واسم المؤلف لا يُصنِّفان أبدًا.** كتاب «النكت على مذهب الشافعي» في فئة حنفية يبقى
حنفيًا بحسب فئته، مع `title_hint_conflicts:shafii` و`needs_review`.

## 8. لا يُشحن أي محتوى للشاملة

| | |
| --- | --- |
| نصوص الكتب | ❌ لا في المستودع ولا في MCPB |
| قواعد بيانات الشاملة أو فهارسها | ❌ |
| JRE أو Lucene jars | ❌ — تُستعمل نسخة الشاملة نفسها؛ الحزمة فيها أصنافنا المترجَمة فقط |
| مفاتيح أو أسرار | ❌ |

يفرضه `scripts/check-no-shamela-data.mjs`، ويفحص ما يتتبعه git وما ستشحنه `npm pack`.
والاختبارات تعمل على مجموعة **اصطناعية** مُولَّدة، لا تحوي نصًّا لأي كتاب.

## 9. ما تكتبه الأداة

| | |
| --- | --- |
| فهرس البحث | **لا شيء** — لا تبني الإضافة فهرسًا، بل تقرأ فهرس الشاملة نفسه |
| ملفات التصدير | `FIQH4_OUTPUT_DIR` — خارج مجلد الشاملة |
| **مجلد الشاملة** | **لا شيء إطلاقًا** — `readOnly: true` يجعل SQLite نفسه يرفض الكتابة |

وكل مسار إخراج يمرّ عبر `resolveSafeOutputDir`: يُقارن بـ realpath، فيرفض التسلّق بـ `..`،
ويرفض المسار المطلق خارج جذر الإخراج، ويكشف الرابط الرمزي الذي يشير إلى المكتبة.
